تشغيل MUZN Operations كتطبيق (PWA) على الآيفون
================================================

1) ارفع محتويات هذا المجلد كما هي (index.html و manifest.webmanifest و sw.js ومجلد icons)
   على أي استضافة ثابتة تدعم HTTPS، مثل:
   - Netlify Drop: اسحب المجلد إلى app.netlify.com/drop
   - Cloudflare Pages أو GitHub Pages (مجاناً)
   مهم: يجب أن يكون الرابط https حتى تعمل خدمة العمل دون اتصال.

2) على الآيفون افتح الرابط في Safari ثم:
   زر المشاركة  ←  «إضافة إلى الشاشة الرئيسية»  ←  إضافة.
   سيظهر التطبيق بأيقونته ويفتح بملء الشاشة.

3) الدخول الأول (بيانات تجريبية):  المدير  admin  /  admin123
   غيّر كلمة المرور فوراً، ثم من الإدارة ← البيانات ← «بدء شركة جديدة» لمسح البيانات الوهمية.

تنبيه: البيانات تُحفظ على كل جهاز على حدة. لمشاركة نفس البيانات بين عدة أجهزة يلزم ربط التطبيق بقاعدة بيانات
(Supabase أو Firebase). خذ نسخة احتياطية دورية من الإدارة ← البيانات.
